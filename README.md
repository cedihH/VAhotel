# VAhotel

The Spring Boot application is in [`hotel-clean-repo`](VAhotel/matcha-lover-hotel-feature-secure-customer-registration-approval/hotel-clean-repo).

## Start developing

Requirements: JDK 21 and Maven 3.9 or newer.

```bash
cd VAhotel/matcha-lover-hotel-feature-secure-customer-registration-approval/hotel-clean-repo
mvn spring-boot:run
```

Open <http://localhost:8080>. For service credentials, initial admin setup, and test commands, see the [application README](VAhotel/matcha-lover-hotel-feature-secure-customer-registration-approval/hotel-clean-repo/README.md).

The nested project README and POM are the canonical application setup instructions. `Matcha-Lover-Hotel.zip` is a packaged snapshot and should be refreshed when preparing a new release.
